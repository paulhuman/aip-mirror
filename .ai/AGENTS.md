# AI agent instructions

1. Treat `.ai/` as the AI working infrastructure and `docs/` as project
   knowledge. DO NOT infer repository or project conventions from memory.

2. Before performing project or `.ai` work, establish repository and path
   context from `.ai/config.yaml` and `.ai/rules/repository.md`.

3. For AI-infrastructure operations, use `.ai/INDEX.md` as the operational
   router and capability map. INDEX routes to canonical owners; it does not
   replace them.

4. For project work, read `docs/PROJECT-INSTRUCTIONS.md` and follow its
   routing to canonical project sources.

5. Re-read the canonical rule, skill, workflow, or project source that owns
   the operation before executing it.

6. When initializing a new conversation chapter, use `paulhuman/aip-mirror@main:/.ai/workflows/handoff/BOOTSTRAP.md` as the canonical chat-initialization workflow; DO NOT invent a separate entry procedure.

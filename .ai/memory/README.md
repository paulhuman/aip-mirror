# Рабочая память AI-инфраструктуры

Каталог `.ai/memory/` хранит временный, но требующий сохранения рабочий контекст AI-инфраструктуры: незавершённые исследования, активные TODO, открытые вопросы и задачи, для которых ещё не подтверждено завершение.

## Язык новых документов

**Новые документы в `.ai/memory/` пишутся на русском языке; необходимые технические термины, названия технологий, идентификаторы, пути, имена полей и точные технические обозначения сохраняются в оригинальном написании.** Точные фрагменты внешних спецификаций и цитаты сохраняются в форме, позволяющей проверить их по первоисточнику.

## Содержимое и жизненный цикл

- TODO должны указывать ожидаемый результат и достаточные критерии проверки.
- Работа не считается завершённой только потому, что её описали как завершённую: статус проверяется по актуальному состоянию репозитория и соответствующим evidence.
- Нерешённые вопросы и незавершённые исследования остаются в memory.
- Завершённые, устаревшие или замещённые записи можно переносить в соответствующий раздел `.ai/archives/`, сохраняя полезное историческое свидетельство.
- Этот README описывает назначение и организацию каталога; он не заменяет владельцев процедур и правил.

Каталог организован в один уровень: README и рабочие записи размещаются непосредственно в `.ai/memory/`, без тематических подпапок. При обычной работе не требуется читать все файлы memory. Следует выбирать записи, относящиеся к текущей задаче, а при обслуживании инфраструктуры проверять структуру, README, актуальные указатели и согласованность расположения материалов.
